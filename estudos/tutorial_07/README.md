# Mini-relatório

**Objetivo:** comparar agrupamento com componentes geométricas conhecidas.

**Ideia matemática:** centroides, grafos e densidade respondem a perguntas diferentes.

**Experimento:** Varri inicializações, vizinhos, escalas, persistência H0 e uma grade de curvas elípticas.

**Resultado:** A primeira ponte entre círculos surgiu no rank 27; com N=3000, a grade acertou 96.8%.

**Limite:** Escala, janela, densidade e ruído impedem interpretar todo cluster como componente da curva.
