# Mini-relatório

**Objetivo:** verificar um ambiente computacional reproduzível.

**Ideia matemática:** uma semente fixa controla a aleatoriedade, mas não substitui o registro de versões.

**Experimento:** foram testados amostragem esférica, sistema linear e derivação automática.

**Resultado:** os três testes passaram; versões estão em resultados/ambiente.csv.

**Limite:** esta verificação é do ambiente de execução do pacote; instalação pessoal e publicação no GitHub continuam sendo ações locais.
