# Mini-relatório

**Objetivo:** ligar projeção, espectro e regularização aos modelos lineares.

**Ideia matemática:** o espaço de funções, a norma penalizada e a base têm papéis distintos.

**Experimento:** foram resolvidos seis exercícios com projeção exata, Laplacianos, curvas polares e otimização.

**Resultado:** a projeção é 3z/5; SGD e a solução ridge coincidiram numericamente; logística manual/PyTorch diferiu 5.6e-17.

**Limite:** colunas reescaladas não acrescentam informação; Weyl no grafo sofre viés de discretização; as conclusões dependem do regime amostral.
