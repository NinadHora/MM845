# Mini-relatório

**Objetivo:** comparar informação de conjunto, interações e ordem.

**Ideia matemática:** permutação preserva diâmetro, mas elimina o sinal da área orientada.

**Experimento:** Treinei DeepSets, MLPs e atenção, ablatei extremos e comparei posições sinusoidais.

**Resultado:** O modelo sem ordem ficou em 50% no sinal; com posição obteve 99.8%.

**Limite:** Ablacionar atenção não remove o caminho residual, e concentração não é causalidade completa.
