# Mini-relatório

**Objetivo:** estudar medida, distância, simetria e aprendizagem em esferas.

**Ideia matemática:** a representação e a partição dos dados mudam o problema estatístico.

**Experimento:** foram resolvidos os 12 exercícios, com testes geométricos, curvas de aprendizagem e transferência de curvatura.

**Resultado:** a triangulação deu χ=2; o enlace numérico foi 1.0000; a validação escolheu grau 3.

**Limite:** vazamento não garante sucesso de um modelo linear; erro contra alvo sem ruído não tem piso sigma²; transferência entre superfícies exige avaliação própria.
